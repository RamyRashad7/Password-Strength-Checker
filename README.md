# 🔐 Password Strength Checker & Generator

A Java console application designed to analyze password security, provide character breakdown metrics, and generate secure custom passwords.

---

##  Features

 **Password Evaluation:** Calculates password strength score (out of 10) based on complexity criteria.
 **Character Analysis:**
 * Checks presence and count of Uppercase, Lowercase, Numbers, and Special symbols.
 * Validates minimum password length (at least 8 characters).
 **Password Generation:**
 * Generates targeted passwords (Uppercase-only, Lowercase-only, Digits-only, Special symbols-only).
 * Generates strong, multi-character type passwords with customizable length.
